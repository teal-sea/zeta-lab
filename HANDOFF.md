# HANDOFF: session records (retired)

This file held the laboratory's dated session records: what each working session did,
what it left open, and the standing Walls and Leads sections. On 2026-10-22 it was retired
from the current tree, because session logistics are operating detail rather than research
record. The results it pointed to live in their own places: each hunt's `RESULTS.md`, the
case log in [`hunts/README.md`](hunts/README.md), and the numbered documents in
[`docs/`](docs/README.md).

Citations elsewhere in this repository of the form `HANDOFF.md` or `HANDOFF.md:NNN` refer
to the last full version, which is preserved unchanged at commit
[`e35c5ea1d`](https://github.com/teal-sea/zeta-lab/blob/e35c5ea1db87e48bc5473766e5eb5ffb22e4a1c5/HANDOFF.md).
