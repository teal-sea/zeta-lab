## 1. Theorem Statement with Exact Normalization

### 1.1 Mathematical Setting and Normalization

Let chi be the odd Dirichlet character modulo 5 with chi(2) = i. The Davenport-Heilbronn Dirichlet series is:
    f(s) = ((1 - i*kappa)/2) * L(s, chi) + ((1 + i*kappa)/2) * L(s, chibar) = sum_{n=1}^infty a_n n^{-s},
with kappa = (sqrt(10 - 2*sqrt(5)) - 2) / (sqrt(5) - 1). The coefficients a_n are periodic mod 5: (1, kappa, -kappa, -1, 0).
The completed function:
    F(s) = (pi / 5)^{-(s+1)/2} * Gamma((s+1)/2) * f(s)
is an entire function of order 1 satisfying the exact functional equation F(s) = F(1 - s).

The log-derivative coefficients Lambda_f(n) are defined by -f'(s)/f(s) = sum_{n=2}^infty Lambda_f(n) n^{-s}:
    Lambda_f(n) = a_n log n - sum_{d | n, 1 < d < n} Lambda_f(d) a_{n/d},   Lambda_f(1) = 0.
Because f has no Euler product, Lambda_f is supported on all integers n >= 2.

### 1.2 Truncation and Basis

Fix cutoff c = 31 and dimension parameter N = 60. Set L = log c = log(31) approx 3.4339872.
On L^2([0, L]), the orthonormal Fourier basis is:
    U_n(y) = L^{-1/2} exp(2 * pi * i * n * y / L),   n in {-N, ..., N},   dim = 2N + 1 = 121.
The correlation kernel on y in [0, L] is:
    q_{nm}(y) = [sin(2*pi*m*y/L) - sin(2*pi*n*y/L)] / (pi*(n - m))  (n != m),
    q_{nn}(y) = 2*(1 - y/L) * cos(2*pi*n*y/L).

Under reflection y -> L - y, the space decomposes into parity sectors. The even sector has dimension N + 1 = 61 with orthonormal basis:
    e_0 = U_0 = L^{-1/2},
    e_k = (U_k + U_{-k}) / sqrt(2) = sqrt(2/L) * cos(2*pi*k*y/L),   k in {1, ..., N}.
A vector v = (v_0, ..., v_N)^T in R^{N+1} embeds into u in R^{2N+1} via u_0 = v_0 and u_{+-k} = v_k / sqrt(2).

### 1.3 Entire Test Function and Positivity

For v in R^{N+1}, define the entire transform:
    F_v(z) = 2 sin(z L / 2) * sum_{k=-N}^N u_k / (z - 2*pi*k/L)
           = 2 sin(z L / 2) * [ v_0/z + sum_{k=1}^N sqrt(2) * v_k * z / (z^2 - (2*pi*k/L)^2) ].
The induced Guinand-Weil test function is:
    g_v(z) = (1 / L) * F_v(z)^2.
Both F_v and g_v are entire functions of exponential type L/2 and L respectively.

Key Positivity Lemma (Proved): For all real r in R, F_v(r) is real, so:
    g_v(r) = (1 / L) * |F_v(r)|^2 >= 0   forall r in R.
Consequently, every on-line zero of F(s) (where r = gamma is real) contributes a strictly non-negative term 2 * g_v(gamma) >= 0 to the Guinand-Weil sum.

### 1.4 The Truncated Matrix Assembly

The Davenport-Heilbronn truncated Weil matrix Q_{DH} in Sym_{2N+1}(R) is:
    Q_{DH} = -WR - Wp  (no pole block, since F(s) is entire),
where:
    Wp(n, m) = sum_{k <= c} Lambda_f(k) k^{-1/2} q_{nm}(log k),
    WR(n, m) = (1 / 2pi) int_{-infty}^infty [ Re psi(3/4 + i*r/2) - log(pi/5) ] * int_0^L q_{nm}(y) cos(r y) dy dr.
The even-sector restriction is denoted E in Sym_{N+1}(R).

## 3. Tail-Bound Derivation and Unresolved Status

### 3.1 Multipole Expansion of the Ground-State Transform

For r >= T = 120, the mode frequencies omega_k = 2*pi*k/L satisfy omega_k <= omega_N approx 109.7823.
Since T > omega_N, the denominator r^2 - omega_k^2 is strictly positive for all k.
Expanding each term in powers of r^{-2}:
    r / (r^2 - omega_k^2) = (1 / r) * sum_{m=0}^{M-1} (omega_k / r)^{2m} + omega_k^{2M} / [ r^{2M-1} (r^2 - omega_k^2) ].

Summing over modes yields:
    v_0/r + sum_{k=1}^N sqrt(2) * v_k * r / (r^2 - omega_k^2) = sum_{m=0}^{M-1} mu_{2m} / r^{2m+1} + R_{2M}(r),
where the signed moments are:
    mu_0 = v_0 + sum_{k=1}^N sqrt(2) * v_k,
    mu_{2m} = sum_{k=1}^N sqrt(2) * v_k * omega_k^{2m}  (m >= 1).

Because the ground-state eigenvector v has alternating signs (v_0 > 0, v_1 < 0, v_2 > 0, ...), strong cancellation occurs in the low-order moments:
    mu_0 = +2.56474e-14,
    mu_2 = -8.80688e-09,
    mu_4 = +4.00119e-04,
    mu_6 = -5.68617e+00.

The remainder is bounded by:
    |R_{2M}(r)| <= C_{2M} / [ r^{2M-1} (r^2 - omega_N^2) ],   C_{2M} = sum_{k=1}^N sqrt(2) * |v_k| * omega_k^{2M}.

### 3.2 Pointwise Envelope and Full Integration-by-Parts Derivation

Using |sin(r L / 2)| <= 1, we obtain the non-increasing pointwise envelope for all r >= T:
    |F_v(r)| <= 2 * [ sum_{m=0}^{M-1} |mu_{2m}| / r^{2m+1} + C_{2M} / [ r^{2M-1} (r^2 - omega_N^2) ] ] =: F_env(r).
    2 * g_v(r) <= (2 / L) * F_env(r)^2 =: G_env(r).

Let N(t) = N_bar(t) + S(t) be the counting function with smooth component dN_bar(t) = d_mean(t) dt and fluctuation term S(t).
Assume an increasing error envelope |S(t)| <= B(t) with B'(t) >= 0.
Integration by parts for non-negative, decreasing G_env(t) yields:
    sum_{gamma > T} G_env(gamma) = int_T^infty G_env(t) dN_bar(t) - G_env(T) S(T) - int_T^infty S(t) G_env'(t) dt.
Since G_env'(t) <= 0 and -S(T) <= B(T):
    -int_T^infty S(t) G_env'(t) dt <= int_T^infty B(t) (-G_env'(t)) dt = B(T) G_env(T) + int_T^infty B'(t) G_env(t) dt.
Adding -G_env(T) S(T) <= B(T) G_env(T), conditional on the existence of a valid increasing envelope B(t) with |S(t)| <= B(t) and B'(t) >= 0 for Davenport-Heilbronn, the resulting upper bound expression is:
    Tail_{> T} <= int_T^infty G_env(t) [d_mean(t) + B'(t)] dt + 2 B(T) G_env(T).
Notice that this IBP expression is explicitly conditional on a valid increasing DH envelope B and is never called a conservative bound before that condition is rigorously established.

### 3.3 Why Conservative Tail Bound is Marked ATTEMPT_UNRESOLVED

The tail bound cannot be claimed as a conservative DH zero tail theorem for two fundamental reasons:
1. Lack of explicit DH counting majorant: Standard Backlund bounds (such as |S(t)| <= 0.2 log t + 2.5 or the lab's Q(t) in `zeta/weil.py:615-644`) were derived specifically for the Riemann zeta function or primitive Dirichlet L-functions. The Davenport-Heilbronn function is a linear combination of two L-functions with off-line zeros; no explicit counting-function majorant valid for Davenport-Heilbronn is established from local primary sources.
2. Unbounded off-line terms: The envelope G_env is defined on the real axis and bounds only on-line zeros (where gamma is real). It does not control off-line zeros Q_k where Im(rho) != 1/2.

Consequently, the tail theorem is marked ATTEMPT_UNRESOLVED, and `tail_bound.py` and `gate_checker.py` refuse to validate it as a conservative analytic bound.

### 3.4 Audit of Defects in Prior Scout Mean-Density Tail

The prior scout script `dhneg_localize.py` evaluated the tail via:
    tail = mp.quad(lambda r: gv(r) * dens(r), [120, 200, 400, 600])  (reported 2.956e-30).

Two distinct defects were identified:
1. Factor-of-2 omission: In the Guinand-Weil explicit formula, each zero pair +-gamma contributes 2 * g_v(gamma). The prior code integrated g_v(r) rather than 2 * g_v(r), understating the integral by a factor of 2.
2. Truncation defect: The upper limit 600 omitted the tail on [600, infty), which contributes approx 8.12e-31.

When corrected, the full mean-density integral (`corrected_mean_density_integral`) on [120, infty) is 6.725e-30 (ratio 2.27x over the reported 2.956e-30).
The unexplained residual at cell (31, 60) in JSON is:
    residual = (lambda_min - Q_1) - S_on = 7.625194...e-30.
This mean-density integral is a heuristic diagnostic model and must not be subtracted or presented as a true zero tail or bound. As a heuristic diagnostic only, the arithmetic difference between the unexplained residual and the corrected mean-density integral is approx 9.00e-31 (1.34% of |Q_1|).
The previously reported figure of 7.87e-31 was unreproducible arithmetic and has been removed.
