  `S = {|z| >= x_0, |arg z| <= theta}` the function h is holomorphic (real on the

- **(P3)**, route 1 of H3 only: Holland's (25),
  `|h^(5)(x + w)| <= C/(x^4 log x)` for real `x >= x_*` and `|w| <= eta x`.

Nothing else from the paper is used. In particular Holland's Lemma 6.1 is not used: H1
follows its method (a contraction in scaled variables), not its result, which is about
the D-fixed system.

Two facts used throughout. **Disk geometry:** a disk of radius `rho x` about a real
`x` lies in `{|arg z| <= arcsin rho, |z| >= (1 - rho) x}`; with
`eta := min(sin theta, 1/4)/2` and `x >= 2 x_0 + 2`, every disk `|zeta - (x + w)| <= eta x`
with `|w| <= eta x` lies in S. **Cauchy's inequality:** if F is holomorphic on
`|zeta - z| <= rho` with `|F| <= M` there, then `|F^(m)(z)| <= m! M rho^(-m)`.

## 2. Derivatives of h of every order

> **Lemma S.** Assume (P1), (P2). For every `k >= 2` there are `C_k`, `C'_k`, `x_k` such
> that for real `x >= x_k`:
>
> (a) `|h^(k)(x + w)| <= C_k/(x^(k-1) L_x)` whenever `|w| <= eta x`;
>
> (b) `h^(k)(x) = (-1)^k 2 (k-2)!/(x^(k-1) L_x) (1 + e_k(x))` with `|e_k(x)| <= C'_k/L_x`;
>
> (c) `e_k(x) = (H_(k-2) - 1)/L_x + O(1/L_x^2)`, `H_m` the m-th harmonic number (`H_0 = 0`).

For k = 2, 3, 4, (b) is Holland's (21) to (23), and (a) at k = 4, 5 is his (24), (25).
New here: the asymptotic (b) at k = 5 (his (25) is an upper bound only), every order
k >= 6, and the first-order constants (c). H1 needs (b) at k = 2..5; H3 is (a) at k = 6.
**Status: derivation, self-reviewed.** The Cauchy factors are explicit; `C_k`, `C'_k`,
`x_k` are not, because they inherit `C_R`, `theta`, `x_0` from (P1).

*Proof.* Differentiate (18) k times: `h^(k)(z) = 2^k G_0^(k)(N) + E_l^(k)(z) + R^(k)(z)`.

*The remainder.* On the disk of radius `eta x` about `x + w`, `|zeta| >= (1 - 2 eta) x`,
so `|R^(k)(x + w)| <= k! (eta x)^(-k) C_R ((1 - 2 eta) x)^(-1+eps_0)`. Relative to the
claimed main term this is `O(L x^(-2+eps_0))`.

*The elementary terms.* `E_l^(k)(z) = (-1)^(k-1) (k-1)! (z^(-k) + (z - 1/2)^(-k))`,
relative size `O(L/x)`.

*The main term, in the variable N.* From (16), `L' = L/Q` (Holland's own identity).
Substituting it into the derivative of (17) and using
`Q = N + L N - (3/4) L^2` collapses the result to

```
    G_0'(N) = log L + rho_G(N),        rho_G = (1 + L)/Q - Q'/(2Q),
```

(pinned numerically at 24 points, defect below 1e-60). So `G_0^(k) = (1/Q)^(k-2) + rho_G^(k-1)`
for `k >= 2`. Write `Q = N L (1 + u)`, `u = 1/L - 3L/(4N)`; (P2) gives `|u| <= 1/4 + 3/32`.
Then `Q' = 1 + L + (1 - 3L/(2N))/(1 + u)` and `|rho_G| <= 2/|N|`, so Cauchy gives
`rho_G^(k-1) = O(N^(-k))`, relative size `O(L/N)`. Next `1/Q = phi (1 + v)` with
`phi = 1/(N L)` and `v = (1 + u)^(-1) - 1 = O(1/|L|)`.

- `(1/L)' = -1/(L Q) = -(1 + v)/(N L^2)`; along a disk of radius `rho |N|`,
  `|L_zeta - L_N| <= 2 rho/(1 - rho)`, so `|L|` changes by a factor within `[5/6, 7/6]`
  for `rho <= 1/4`. Cauchy on `(1/L)'` gives `(1/L)^(i) = O(N^(-i) L^(-2))` for `i >= 1`.
- Leibniz: `phi^(m) = sum_i C(m,i) (N^(-1))^(m-i) (1/L)^(i) = (-1)^m m!/(N^(m+1) L) (1 + O(1/L))`.
- `|phi v| = O(1/(N L^2))` on disks, so Cauchy gives `(phi v)^(m) = O(m!/(N^(m+1) L^2))`.

Hence `G_0^(k)(N) = (-1)^k (k-2)!/(N^(k-1) L_N) (1 + O(1/L_N))`, uniformly on the disks,
which is Holland's (26) to (29) sharpened at k = 5 and continued to every k.

*Back to z.* `2^k (-1)^k (k-2)!/((2z - 2)^(k-1) L_(2z-2)) = (-1)^k 2 (k-2)!/((z - 1)^(k-1) L_z)`,
and `(z - 1)^(-(k-1)) = z^(-(k-1)) (1 + O(k/|z|))`. With `|L_(x+w)| >= (5/6) L_x` on the
disk this gives (a) and (b).

*First order (c).* The same induction with the main terms kept:
`(1/L)^(i) = (-1)^i (i-1)!/(N^i L^2) (1 + O(1/L))`, so
`phi^(m) = (-1)^m m!/(N^(m+1) L) (1 + H_m/L + O(1/L^2))`; and `v = -1/L + O(1/L^2 + L/N)`,
so `(phi v)^(m) = -(-1)^m m!/(N^(m+1) L^2) (1 + O(1/L))`. Adding,
`(1/Q)^(m) = (-1)^m m!/(N^(m+1) L) (1 + (H_m - 1)/L + O(1/L^2))`, and `m = k - 2`. QED.

**Measured** (`results_h1_h3.json`, `G0` and `h_circle`):

  `(-1)^k (k-2)!/(N^(k-1) L_N)` is 1.127 (k = 6, N = 1e3), 1.025 (1e20) and 1.0097 (1e50),
  and on the complex rays `arg N = 0.25` and `0.5` its modulus agrees with the real value,
  over k = 2..6, to relative 1.4e-3 at `|N|` = 1e3, 3.2e-6 at 1e20 and 1.9e-7 at 1e50. `(ratio - 1) L_N` at N = 1e50, k = 2..6:
  -0.991, -0.018, 0.477, 0.810, 1.062, against (c)'s -1, 0, 0.5, 0.833, 1.083; the gap
  closes like 1/L at every k.
- The full h on a complex circle: h computed from Holland's (15) by quadrature at 64 points
  of `|z - n| = n/8` (n = 400 and 3200; trapezoid coarse/fine below 5e-41) has Taylor
  coefficients at n that agree with route B's real-axis derivatives for k = 2..7 to
  relative 4e-20 to 1e-17 (n = 400) and 5e-26 to 3e-23 (n = 3200). On `|z - n| = n/16`, `max |h^(6)|` is 1.52 (n = 400) and 1.54
  (n = 3200) times `48/(n^5 L_n)`; and Holland's remainder R varies on the circle by at
  most 0.028/n and 0.038/n. This measures (P1) at two n; it does not establish it.

## 3. H3: the sixth derivative

> **H3.** There are `eta_6 > 0`, `C_6`, `x_6` with `|h^(6)(x + w)| <= C_6/(x^5 log x)` for
> real `x >= x_6` and complex `|w| <= eta_6 x`.

`1/(x^5 L_x)` and `1/(x^5 log x)` are interchangeable up to a factor 2 for large x, as
Holland treats them.

### 3.1 Route 1: one Cauchy estimate on Holland's (25)

Let `|w| <= eta x/2`. The disk of radius `eta x/2` about `x + w` lies in
`{x + w' : |w'| <= eta x}`, where (P3) bounds `|h^(5)|` by `C/(x^4 log x)`. Cauchy with
m = 1: `|h^(6)(x + w)| <= (2 C/eta)/(x^5 log x)`. So H3 holds with `eta_6 = eta/2` and
`C_6 = 2C/eta`. **Status: derivation, self-reviewed, from (P3) alone.** It is one line,
and it is the step `RESULTS.md` 12.4 needed.

### 3.2 Route 2: Holland's own route, (19) at r = 6 and (29) carried once more

*(19) at r = 6.* For z in `S' = {|arg z| <= theta/2, |z| >= 2 x_0}` put
`delta = min(sin(theta/2), 1/2)`. The disk `|zeta - z| <= delta |z|` lies in S and
`|zeta| >= (1 - delta)|z|`, so Cauchy gives

```
    |R^(6)(z)| <= 720 delta^(-6) (1 - delta)^(-1+eps_0) C_R |z|^(-7+eps_0),
```

which is (19) at r = 6 with its constant explicit in `C_R`. Nothing restricts r: Holland
needed r <= 5 only.

*(29) carried once more.* Lemma S at k = 6 gives
`G_0^(6)(N) = 24/(N^5 L_N) (1 + O(1/L_N))` on the disks, the analogue (29') of his (29)
(where he stated only `G_0^(5) = O(1/(N^4 L_N))`). With `h^(6) = 64 G_0^(6)(2z - 2) +
E_l^(6) + R^(6)` this is H3 with `C_6` from Lemma S(a), and in addition the real-axis
asymptotic `h^(6)(x) = 48/(x^5 L_x)(1 + (H_4 - 1)/L_x + O(1/L_x^2))`.
**Status: derivation, self-reviewed, from (P1) and (P2).**

### 3.3 Carried through to the sixth-order residual (`RESULTS.md` 12.4)

Let (A, B, C, D) be H1's solution, `eps = tau_0` (section 4) and
`E^(6)(z) = h^(6)(n + z) - psi^(5)(b + z) + psi^(5)(B + z) + psi^(5)(D + z) - psi^(5)(A + z) - psi^(5)(C + z)`.
For complex `|z| <= eta_6 n`:

1. For `Re y > 0`, `|psi^(5)(y) - 24/y^5| <= 120/(Re y)^6`. From the integral representation,
   the difference is `int_0^inf t^4 e^(-yt) (t/(1 - e^(-t)) - 1) dt`, and
   `0 <= t/(1 - e^(-t)) - 1 <= t`.
2. `24/(p + z)^5 = f_z(n/p)` with `f_z(w) = 24 w^5/(n + z w)^5` and `f_z(0) = 0`, so the five
   leading terms sum to `-int_G f_z'(t) dt` over the gap set G of section 4.1.
3. `|f_z'(t)| = 120 n t^4/|n + z t|^6 <= 120/((1 - eta_6)^6 n^5)` for `0 <= t <= 1`.
4. H1 gives `|G| <= eps (1 + 13r/4) + 1/(2n + 1)` (`g0 + gx + g1` on the box of section
   4.3) and every parameter at least n, so `Re(p + z) >= (1 - eta_6) n`.

Hence

```
    sup_{|z| <= eta_6 n} |E^(6)(z)| <= C_6/(n^5 log n) + 120 (eps (1 + 13r/4) + 1/(2n+1))/((1 - eta_6)^6 n^5)
                                       + 600/((1 - eta_6)^6 n^6),
```

and with `eps <= 2/L_n` (measured at every n: `tau_0 L/2` is 0.87 to 0.977 from 1e4 to
1e20, and `1 - 1/L + O(1/L^2)` by Lemma S(c)) the second term is at most
`240 (1 + 13r/4)(1 - eta_6)^(-6)/(n^5 L_n)` plus an `O(1/n^6)` part. This is 12.4's bound
`sup |E^(6)| <= C/(n^5 log n)` with every constant explicit except `C_6`.
**Status: derivation, self-reviewed.**

**Measured**: item 1 at nine complex and real points (largest ratio to the bound 0.817,
at y = 1); item 2 at n = 3200 with the route A Pade parameters at z = 0 (difference
`24.8/n^6` against the bound `599/n^6`); and `tau_4 = n^5 Delta^6 h(n)/24` against
`2/L`: `(tau_4 L/2 - 1) L` is 0.86 at n = 1e6 and 1.027 at 1e20, approaching
`H_4 - 1 = 1.083`.

## 4. H1: the matching system at every large n

### 4.1 The system, exactly, in moment form

Holland's (52) with D free and k = 0..3, in his logarithmic form (58), with his (31)
at every k (`log q_k = l(b + k) - delta_k`, `l(y) = log(1 + 1/y)`,
`delta_k = Delta^2 h(n + k)`):

```
    l(B+k) + l(D+k) - l(A+k) - l(C+k) - l(b+k) + delta_k = 0,     k = 0, 1, 2, 3.
```

Apply `(-1)^j n^(j+1)/j! Delta^j` at k = 0 (an invertible triangular recombination). Since
`l(p + k) = Delta log(p + k)`, with

```
    lambda_j(p) := (-1)^j n^(j+1)/j! Delta^(j+1) log(p),     tau_j := (-1)^j n^(j+1)/j! Delta^(j+2) h(n),
```

the system is `lambda_j(B) + lambda_j(D) - lambda_j(A) - lambda_j(C) - lambda_j(b) + tau_j = 0`,
j = 0..3. The model side has a closed form: `(d/dp) Delta^(j+1) log p = Delta^(j+1)(1/p)
= (-1)^(j+1) (j+1)!/(p (p+1) ... (p+j+1))`, so with `u_j(w) := lambda_j(n/w)`

```
    u_j'(w) = (j+1) w^j prod_{i=1}^{j+1} (1 + i w/n)^(-1),     u_j(0) = 0.        (4.1)
```

With `w_P := n/P` and the signed gap set `G = [0, w_A] u [w_B, w_C] u [w_D, w_b]`, the
system is exactly

```
    tau_j = int_G u_j'(t) dt,     j = 0, 1, 2, 3.                                (4.2)
```

This is the exact form of `RESULTS.md` 11.1's moment picture: the targets are moments of
the three gaps, with the weight `prod (1 + i t/n)^(-1)` as the only correction. The targets
`tau_j` are the only place where xi enters.

*Scaled variables.* Put `eps := tau_0` (by Lemma S(b), `eps = (2/L)(1 + O(1/L))`; this is
Holland's (32)) and `X = (g0, gx, g1, x)` by

```
    w_A = eps g0,   w_B = x - eps gx/2,   w_C = x + eps gx/2,   w_D = 1 - eps g1,
```

a bijection onto parameters with `0 < w_A < w_B < w_C < w_D < 1`. Write `Phi_n(X)` for the
vector `(tau_j - int_G u_j')/eps`; the system is `Phi_n(X) = 0`.

**Measured**: at the phase 1 solution, `Phi_n` evaluated through `lambda_j` vanishes to
2e-60 or better at all 21 route A points (n = 50..3200) and below 2e-68 at all 9 route B
points (n = 1e4..1e20), so this reformulation and phase 1's solver describe the same
system.

### 4.2 The decomposition

With `u_j'(t) = (j+1) t^j (1 + rhohat_j(t))`, `rhohat_j = prod (1 + i t/n)^(-1) - 1`, and
`-(j+1)(j+2) t/(2n) <= rhohat_j(t) <= 0`:

```
    Phi_n(X) = Phi_inf(X) + t - eps S(X; eps) + beta - rho(X),
    Phi_inf,j(X) = 1 - [j = 0] g0 - (j+1)(gx x^j + g1),
    t_j  = tau_j/eps - 1                                 (t_0 = 0 by the choice of eps),
    beta_j = (1 - w_b^(j+1))/eps                     in [0, (j+1)/((2n+1) eps)],
    rho_j(X) = ((j+1)/eps) int_G t^j rhohat_j(t) dt,
```

and `eps S_j = P_j(X; eps) - P_j(X; 0)` with
`P_j = [(eps g0)^(j+1) + (x + eps gx/2)^(j+1) - (x - eps gx/2)^(j+1) + 1 - (1 - eps g1)^(j+1)]/eps`:

```
    S_0 = 0,   S_1 = g0^2 - g1^2,   S_2 = -3 g1^2 + eps (g0^3 + gx^3/4 + g1^3),
    S_3 = -6 g1^2 + eps (4 g1^3 + x gx^3) + eps^2 (g0^4 - g1^4).
```

`Phi_inf(X) = 0` says the three-node rule with nodes 0, x, 1 and weights g0, gx, g1 is exact
on `(j+1) t^j`, j = 0..3: its only solution is **Simpson's rule
`X* = (1/6, 2/3, 1/6, 1/2)`**, the Lobatto limit of `RESULTS.md` 11.3.

*The 1/n terms, explicitly.* On the box below every point of G lies in [0, 1] and
`|G| <= eps (g0 + gx + g1) + 1/(2n+1)`, so
`|rho_j| <= (j+1)^2 (j+2)/(2n) (g0 + gx + g1 + 1/((2n+1) eps))`. Differentiating at the
moving endpoints: `|d rho_j/d g0| <= (j+1)^2 (j+2) (eps g0)^(j+1)/(2n)`,
`|d rho_j/d gx|, |d rho_j/d g1| <= (j+1)^2 (j+2)/(2n)` and `|d rho_j/d x| <= (j+1)^2 (j+2)/(n eps)`.

### 4.3 The contraction, with every constant exact

```
    J = D Phi_inf(X*) = [[-1, -1, -1, 0], [0, -1, -2, -4/3], [0, -3/4, -3, -2], [0, -1/2, -4, -2]],
    det J = -1,
    J^-1 = [[-1, 5/2, -8/3, 1], [0, -2, 4/3, 0], [0, -1/2, 4/3, -1], [0, 3/2, -3, 3/2]].
```

`J` is `-diag(1, 2, 3, 4)` times phase 1's moment matrix, whose determinant -1/24 is pinned
in `test_jensen_wedge_phase1.py` (`-1 = 4! (-1/24)`). The norm is the weighted max norm
`||y||_w = max_i |y_i|/w_i` with **`w = (3/4, 1, 3/2, 3/4)`**, and the box is
**`B = {||X - X*||_w <= r}`, `r = 2/25`**. In the deviations `d = X - X*`, the matrix
`I - J^-1 D Phi_inf(X)` has two nonzero columns (gx and x):

```
    row g0: [ 4 dx^3 - 2 dx^2,   12 dgx dx^2 - 4 dgx dx + 8 dx^2 - (8/3) dx ]
    row gx: [ 4 dx^2,             8 dgx dx + (16/3) dx ]
    row g1: [ -4 dx^3 - 2 dx^2,  -12 dgx dx^2 - 4 dgx dx - 8 dx^2 - (8/3) dx ]
    row x:  [ 6 dx^3 - (3/2) dx,  18 dgx dx^2 - (3/2) dgx + 12 dx^2 ]
```

Bounding each polynomial by the sum of its monomials' absolute values on the box gives
the constants (exact rationals, `probe_h1_h3.py`):

| constant | meaning | value |
| --- | --- | --- |
| `kappa` | `sup_B \|\|I - J^-1 D Phi_inf\|\|_w` | **4533/15625 = 0.290112** (largest value on a 21 x 21 grid of the box: 177/625 = 0.2832) |
| `nu_w` | `max_i sum_k \|J^-1_ik\|/w_i` | **86/9** |
| `sigma(eps)` | `sup_B \|\|J^-1 D_X(eps S)\|\|_w`, a polynomial in eps with nonnegative coefficients | 0.0777 (eps = 1/32), 0.1609 (1/16), 0.3439 (1/8; largest sampled value 0.2986) |
| `J^-1 (eps S)(X*; eps)` | the eps part of the initial residual | **`eps (1 - eps) (1/18, -1/9, 1/18, 0)`** exactly |
| admissibility | every X in B has `0 < w_A < w_B < w_C < w_D < 1` | **iff eps < 2/3** |

> **Lemma C (explicit contraction).** Let n >= 1, let `tau_0 > 0, tau_1, tau_2, tau_3` be
> given, `eps = tau_0 < 2/3`, and put
>
> ```
>     q   := kappa + sigma(eps) + nu_w rho'(n, eps),
>     d_0 := ||J^-1 (t - eps S(X*; eps))||_w + nu_w max_j (beta_j + rho_j),
> ```
>
> with `rho'` the largest w-weighted row sum of the derivative bounds of section 4.2 and
> `beta_j`, `rho_j` their bounds there. If `q < 1` and `d_0 <= (1 - q) r`, then (4.2) has
> exactly one solution with X in B, it has `A > B > 0` and `C > D > 0`, and
> `||X_n - X*||_w <= d_0/(1 - q)`.

*Proof.* `T(X) = X - J^-1 Phi_n(X)` has
`DT = (I - J^-1 D Phi_inf) + J^-1 D(eps S) + J^-1 D rho`, so `||DT||_w <= q` on the convex
box, and `T(X*) - X* = -J^-1 (t - eps S(X*) + beta - rho(X*))` has w-norm at most `d_0`.
For X in B, `||T(X) - X*||_w <= q r + d_0 <= r`: T maps B into itself and contracts, so it
has one fixed point, which is a zero of `Phi_n`, and every zero in B is a fixed point.
The radius bound is `||X_n - X*|| <= q ||X_n - X*|| + d_0`. Admissibility gives the
signs. QED. **Status: derivation, self-reviewed; every constant exact.**

A uniform sufficient form, for reading `n_0`: with `eps <= 1/16` and `n eps >= 1e5` one has
`q <= 0.4574`, `(1 - q) r >= 0.0434`, the eps part of `d_0` at most `eps/9 <= 0.0070` and
the `1/n` parts at most 0.0005, so the lemma applies whenever **`||J^-1 t||_w <= 7/200`**.

*Remark (a measured symmetry, derived).* With constant density, `RESULTS.md` 11.3 measured
`a1 + b2 = b1 + a2 = 1` without deriving it. The constant-density moment conditions are
invariant under `t -> 1 - t`, which maps a configuration with gaps at 0, inside and at 1
to another of the same shape, `(g0, gx, g1, x) -> (g1, gx, g0, 1 - x)`. For small eps
the solution lies within `O(eps)` of `X*`, so it and its reflection both lie in B, and
uniqueness in B (Lemma C) forces them to coincide. The x-component of `J^-1 (eps S)(X*; eps)` above
is exactly 0 for the same reason. For every eps it follows from uniqueness of the [2/2]
Pade approximant, a classical fact not re-proved here.

### 4.4 The targets, and the first order

> **Lemma T.** Assume Lemma S(b) for k = 2..5. Then

### 4.5 H1

> **H1.** Assume (P1) and (P2). There is `n_0` such that for every integer `n >= n_0`
> Holland's four-parameter system with D free (his (52) at k = 0..3) has a solution
> (A, B, C, D) with `A > B > 0`, `C > D > 0`, unique in the box B of the scaled variables,
> with `||X_n - X*||_w <= d_0/(1 - q) = O(1/L_n)`. In the original parameters:
> `A = 3nL(1 + O(1/L))`, `B = 2n(1 + O(1/L))`, `C = 2n(1 + O(1/L))`,
> `D = n(1 + 1/(3L) + O(1/L^2))`, `B - C = (16n/(3L))(1 + O(1/L))`, and the gap total
> `w_A + w_C - w_B + 1 - w_D = (2/L)(1 + O(1/L))`: within relative `O(1/L)` of the
> leading-order [2/2] Pade configuration.

*Proof.* By Lemma T, `eps -> 0` and `t -> 0` like 1/L, and `n eps -> infinity`; then
`sigma(eps) -> 0`, `rho' -> 0` and `d_0 -> 0` while `kappa = 0.290 < 1`, so Lemma C applies
for all large n. Its radius bound gives the rest by substitution. QED.
**Status: derivation, self-reviewed.**

*What is explicit and what is not.* Explicit and exact: the system (4.2), `X*`, `J`,
`J^-1`, the weights, `r`, `kappa`, `nu_w`, `sigma(eps)`, every 1/n bound, the admissibility
range `eps < 2/3`, and the uniform condition `||J^-1 t||_w <= 9/250` (with `eps <= 1/16`,
`n eps >= 1e5`). **Not explicit: `n_0`.** The condition is on the data `t(n)`, and the
rate at which `t(n) -> 0` comes from Lemma S, whose constants inherit `C_R`, `theta`,
`x_0` of (P1), which neither Holland nor GORTTW makes explicit. The missing step for an
explicit `n_0` is an explicit form of (P1), that is an explicit error term in GORTTW's
complex saddle estimate (3.2); that is phase 2's object (MISSION Q2), not H1's. As with
Holland's section 10, the finite range `n < n_0` is absorbed into the eventual constant
of the wedge, so H1 as the chain uses it needs no explicit `n_0`.
